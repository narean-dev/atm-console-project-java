# 🏦 ATM Console Application

A robust Java-based command-line application that simulates real-world ATM functionalities. Designed with clean code principles and easy-to-use menu navigation.

---

# 🚀 Features
* Secure Access : Built-in PIN verification system.
* Balance Check : Real-time account balance updates.
* Cash Withdrawal : Dynamic balance deduction after verification.
* Infinite Loop Navigation : Smooth user experience using `while(true)` logic.

---

# 🛠️ Technical Stack
* Language : Java (JDK 8+)
* Input Handling : `java.util.Scanner`
* Version Control : Git & GitHub
